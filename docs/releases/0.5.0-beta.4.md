# TaskNotes Task Control 0.5.0-beta.4

## Changes

- Restore the compact task chip layout with TaskNotes 5, including the priority indicator placement. TaskNotes 4 remains supported.
- Show Session and Total side by side on active timer cards in both the Timers and Staged panes when space permits.
- Add a checkmark icon to the Complete button alongside the existing timer control icons.
- Retain staged subtask grouping, collapsible branches, hierarchy guide lines, and reordering within each displayed branch from beta.3.

## Verification

Build, lint, and automated tests cover this release. Isolated desktop checks with TaskNotes 5.0.5 also verified Pomodoro timer ownership, preservation of manual timers, and completion after a simulated renderer delay. Physical sleep was not tested. This beta has not been verified through a BRAT update or on a physical mobile device.

## Install

In BRAT, select version `0.5.0-beta.4` for `judealnas/obsidian-tasknotes-task-ctrl`. The minimum Obsidian version remains 1.12.2.
