# TaskNotes Task Control 0.3.0-beta.2

Beta update from `milestone-v0.3`, incorporating feedback on beta.1.

## Changes since beta.1

- Removed Done today and the rollover-hour setting. Staged tasks now stay in their saved order until completed or unstaged. Days-staged counts and recurring completion requests use local calendar dates.
- Removed automatic external completion-history collection and daily history resets. Completion safety records remain to prevent repeated or uncertain recurring writes. Existing safety records, pauses, orders and foreign plugin data are preserved; the retired rollover setting is dropped on the next normal save.
- Added full-width rounded **+** buttons before, between and after staged cards. Each opens the batch picker at that position; multiple selections keep their selection order. The Stage header button still appends tasks.
- Added edge scrolling while dragging cards to reorder them.
- Removed the visible Paused label; muted timer numbers indicate pause.
- Fixed narrow-pane button/chip overflow and spacing between tab names and counts.

## Verification and remaining limits

Build, lint and **636 automated tests in 28 files** pass. Tests for the removed Done today/custom-rollover features were replaced with calendar-date, migration, insertion-order, picker-anchor and scroll-cleanup checks.

Native desktop checks with TaskNotes 4.18.2 verified no horizontal overflow at 160/200/280/400px in idle/running/paused UI models, correctly positioned picker openings, count spacing, and edge scrolling with synthetic drag events. No actual task completion or staging writes were used for those layout checks.

Physical mobile/touch and an actual BRAT update to this published beta remain unverified. Earlier native recurrence and cold-upgrade evidence remains recorded; it is not a new beta.2 BRAT-upgrade pass. Overnight/custom-rollover acceptance is superseded by removal of that feature. Stable 0.3.0 acceptance is not declared complete.

## Install

In BRAT, select `judealnas/obsidian-tasknotes-timer-pane` and version `0.3.0-beta.2`. Back up your vault and plugin data before testing. This updates the existing `tasknotes-timer-pane` installation.

BRAT users tracking latest may receive prereleases; pin `0.2.0` to stay on stable. GitHub's Latest release remains 0.2.0.

Minimum Obsidian: 1.12.2. Regular timers require TaskNotes 4.10.0+; staging and recurring completion require 4.13.0+ and the relevant public API capabilities. Register TaskNotes user field `staged` as Date with no default value.
