# TaskNotes Task Control 0.5.0

## Changes

- Cards in **Timers** and **Staged** show clickable parent tasks and an expandable **Subtasks** list with completion progress. Related tasks use native TaskNotes chips when the link overlay is enabled.
- Staged subtasks appear as indented cards beneath their nearest staged ancestor, with guide lines and independent controls to collapse each branch. Unstaged subtasks remain visible in the parent's **Subtasks** list.
- Drag a card or focus its grip and press Up or Down to reorder cards under the same displayed parent. Moving a parent carries its descendants with it.
- Task chips retain the compact layout, including priority indicator placement, with both TaskNotes 4 and 5.
- Active cards show **Session** and **Total** side by side when space permits. The **Complete** button has a checkmark icon.

## Verification

The release is checked by the production build, lint, and automated tests. Isolated desktop checks during the beta cycle covered task chips, nested staging, and Timer Pane compatibility with TaskNotes 4 and 5.

## Install

In BRAT, add `judealnas/obsidian-tasknotes-task-ctrl` and select `0.5.0`. The minimum Obsidian version is 1.12.2. Relationship features require TaskNotes' public relationship API.
