# TaskNotes Task Control 0.5.0-beta.2

Beta preview refining parent and subtask task cards.

## Changes

- Parent tasks and subtasks use TaskNotes' title chips, including its native status and interaction controls when the TaskNotes link overlay is enabled.
- The pane hides scheduled dates inside title chips and aligns relationship chips with their surrounding text.
- Beta.1's parent navigation, expandable immediate subtasks, and completion summary remain available.

## Verification

The relationship chip behavior was checked in a temporary desktop vault with Obsidian 1.15.1 and TaskNotes 4.18.2. Parent and subtask context menus opened the corresponding notes; the overlay-off fallback remained clickable. A 256 px card had no horizontal overflow. The local stylesheet preview confirmed scheduled-date removal and baseline alignment. Beta.2 has not been installed through BRAT. Physical mobile behavior remains unverified, and this beta does not close outstanding acceptance items from earlier GSD phases.

The release build, lint, and automated checks are recorded by the beta.2 GitHub Actions workflow.

## Install

In BRAT, add `judealnas/obsidian-tasknotes-task-ctrl` and select `0.5.0-beta.2`. BRAT's Latest tracking can also select this prerelease. GitHub's Latest stable release remains separate.

Minimum Obsidian version: 1.12.2. Relationship rows require the corresponding TaskNotes public relationship API methods; they were verified with TaskNotes 4.18.2. Regular timer compatibility is unchanged.
