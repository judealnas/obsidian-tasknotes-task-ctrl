# TaskNotes Task Control 0.4.0

This release moves TaskNotes Task Control to the renamed repository and a new Obsidian plugin ID.

## Changes

- Plugin ID and install folder are now `tasknotes-task-ctrl` and `.obsidian/plugins/tasknotes-task-ctrl/`.
- Obsidian command IDs now use the `tasknotes-task-ctrl:` prefix.
- The GitHub repository is now `judealnas/obsidian-tasknotes-task-ctrl`.
- The saved pane view type remains `tasknotes-timer-pane`, preserving the view identity used by Obsidian layouts.
- Updated the development build, UAT launch and smoke-check scripts, and vault-switch helper for the new plugin ID and repository.
- Updated installation and release references in the README.

## Verification

The release workflow runs the production build, lint, automated tests and vault-switch tests, then checks that tag `0.4.0` matches the manifest version before publishing the release assets.

## Install

In BRAT, add `judealnas/obsidian-tasknotes-task-ctrl` and select version `0.4.0`. Manual installation uses the new plugin folder shown above.

Minimum Obsidian version: 1.12.2. Regular timers require TaskNotes 4.10.0 or later. Staging and recurring completion require TaskNotes 4.13.0 or later and the relevant public API capabilities. Register TaskNotes' `staged` field as a Date field with no default value, or use **Configure staged field** in plugin settings.
