# TaskNotes Task Control 0.3.0

Stable release of the 0.3.0 staging and task-control update.

## Changes since 0.2.0

- Added a Staged tab for daily tasks, with independent ordering, staging dates and contexts, and actions to start, pause, stop, complete or unstage tasks.
- Added persistent idle timer cards and task creation from the Staged and Timers pickers.
- Added recurring-task completion with safeguards against replaying or duplicating writes.
- Added keyboard and mobile arrow controls for reordering cards, plus accessible tab navigation and task counts.
- Renamed the displayed plugin to TaskNotes Task Control while preserving the existing plugin ID, view type, command IDs and saved state.
- Added a full-width **+** button below the Staged and Timers tabs. It adds tasks to the selected tab. In Timers, Pause all, Resume all and Stop all share a full-width row beneath it. The tabs and shared controls stay visible while task cards scroll.
- Added **Configure staged field** at the top of plugin settings. Its description explains the change before you click. The button adds a TaskNotes custom date field with key `staged` and no default. It uses the theme accent color while setup is needed and becomes disabled with green confirmation when the field is correctly configured.
- Added **Stage task** to TaskNotes Note actions.

## Verification

The pane screenshots in the README were captured from a running Obsidian vault. The feature build, lint, 681 automated tests and 13 vault-switch tests passed before release preparation. The release workflow runs `npm run check` and verifies that the tag matches the manifest version before publishing the release assets.

Runtime behavior of the Configure staged field button remains unverified. Physical mobile-device behavior and a BRAT update to this stable release remain unverified.

## Install and compatibility

In BRAT, select `judealnas/obsidian-tasknotes-timer-pane` and version `0.3.0`. This updates the existing `tasknotes-timer-pane` installation.

Minimum Obsidian version: 1.12.2. Regular timers require TaskNotes 4.10.0 or later. Staging and recurring completion require TaskNotes 4.13.0 or later and the relevant public API capabilities. Use **Configure staged field** in plugin settings, or register `staged` manually as a Date field with no default in TaskNotes Custom User Fields. Automated setup uses TaskNotes internals and may need adjustment for future TaskNotes versions. If the key already has a conflicting configuration, setup asks you to review it in TaskNotes.
