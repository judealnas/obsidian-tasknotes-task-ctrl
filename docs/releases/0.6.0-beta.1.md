# TaskNotes Task Control 0.6.0-beta.1

- Use the stopwatch or alarm icon on a task card to choose between elapsed time and a countdown.
- Enter a duration in `MM:SS` or `HH:MM:SS`. Change the initial value under **Settings → TaskNotes Task Control → Default countdown duration**.
- Pause freezes the remaining time. Resume continues the same countdown. Stop puts the remaining time back in the editable duration field.
- When a countdown reaches zero, Task Control stops its time entry as soon as Obsidian and TaskNotes are available and shows a notice. The task stays open.

For BRAT, select `0.6.0-beta.1` for `judealnas/obsidian-tasknotes-task-ctrl`.
