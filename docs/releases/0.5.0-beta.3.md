# TaskNotes Task Control 0.5.0-beta.3

## Changes

- Staged subtasks appear as indented cards beneath their nearest known staged ancestor. File-tree guide lines connect each branch, and each parent can fold its staged descendants independently.
- The **Subtasks** list shows all immediate subtasks as native TaskNotes chips when the link overlay is enabled. A subtask gets a separate card only when it is staged.
- Drag the grip or focus it and press Up or Down to reorder cards that share a parent in the displayed tree. Moving a parent carries its descendants with it.
- Active timer cards in **Staged** show **Session** and **Total** side by side when space permits.

## Verification

Desktop checks in an isolated Obsidian 1.15.1 vault covered two levels of indentation, nested folding, native chips for staged and unstaged subtasks, and guide lines spanning a branch. Automated tests cover sibling reordering and rejection of drops across branches. This beta has yet to be tested through BRAT or on a physical mobile device.

## Install

In BRAT, add `judealnas/obsidian-tasknotes-task-ctrl` and select `0.5.0-beta.3`. The minimum Obsidian version is 1.12.2. Subtask grouping uses TaskNotes' public relationship API.
