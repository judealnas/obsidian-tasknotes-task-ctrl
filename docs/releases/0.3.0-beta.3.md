# TaskNotes Task Control 0.3.0-beta.3

Beta update from `milestone-v0.3`, adding task creation and persistent idle timer cards after beta.2.

## Changes since beta.2

- Added persistent idle cards to the Timers tab. Selected tasks remain available when they are not actively running, so a timer can be started from the same card later.
- Added TaskNotes-native task creation from both the Staged and Timers pickers. The pane opens TaskNotes' creation dialog and uses the resulting task in the originating flow.
- Simplified the empty Staged panel by removing the redundant heading and explanatory text.
- Centered the wide **+** insertion controls and made card-title wikilinks visibly distinct with the link color and an underline.

## Verification and remaining limits

This candidate was built and linted locally. Automated tests were not run locally; the tag workflow is the required test run before publication.

Native acceptance of the new creation flow, physical mobile/touch behavior, and an actual BRAT upgrade to beta.3 remain unverified. Stable 0.3.0 acceptance is still open.

## Install

In BRAT, select `judealnas/obsidian-tasknotes-timer-pane` and version `0.3.0-beta.3`. Back up your vault and plugin data before testing. This updates the existing `tasknotes-timer-pane` installation.

BRAT users tracking latest may receive prereleases; pin `0.2.0` to stay on stable. GitHub's Latest release remains 0.2.0.

Minimum Obsidian: 1.12.2. Regular timers require TaskNotes 4.10.0+; staging and recurring completion require 4.13.0+ and the relevant public API capabilities. Register TaskNotes user field `staged` as Date with no default value.
