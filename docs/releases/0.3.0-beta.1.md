# TaskNotes Task Control 0.3.0-beta.1

Beta release from `milestone-v0.3` for testing. Phase 7 acceptance remains incomplete; this is not the stable 0.3.0 release.

## Changes since 0.2.0

- Stage daily tasks, keep an independent order, and start, pause, stop or unstage them.
- Complete ordinary tasks and recurring occurrences, with replay protection and Pomodoro ownership checks.
- Review Done today and carry unfinished staged tasks across the configured rollover hour.
- Reorder cards using mobile arrow controls.
- Rename the displayed plugin to TaskNotes Task Control while preserving the installed plugin ID, view type, command IDs and saved state.

## Verification and outstanding checks

The candidate has build, lint and 725 automated tests passing. Native TaskNotes 4.18.2 evidence includes completion branches with auto-stop enabled and disabled, plus a cold 0.2.0-to-candidate upgrade rehearsal. That rehearsal used the preceding 0.3.0 candidate, not an actual BRAT update to this beta.

The following have **not** been verified:

- Real overnight rollover with Obsidian left open.
- Physical sleep/wake across the rollover boundary.
- Physical mobile/touch behavior.
- An actual BRAT update to this published beta.

External completion history containing only dates cannot establish exact completion times; ordering is best effort. Native API coverage is limited to the TaskNotes version listed above.

## Install and compatibility

Back up your vault and plugin data before testing. In BRAT, add `judealnas/obsidian-tasknotes-timer-pane` and select `0.3.0-beta.1` specifically. This updates the existing plugin with ID `tasknotes-timer-pane`.

BRAT users tracking latest may receive prereleases. Pin `0.2.0` to remain on the stable version. GitHub's Latest release remains 0.2.0.

Minimum Obsidian: 1.12.2. Regular timers require TaskNotes 4.10.0+; staging and recurring completion require 4.13.0+ and the relevant public API capabilities. Configure the TaskNotes `staged` user field as a date with no default value.
