# TaskNotes Task Control 0.5.0-beta.1

Beta preview of parent tasks and subtasks on task cards.

## Changes

- Cards in Timers and Staged show clickable parent task names when TaskNotes provides them.
- An expandable subtask list shows completion progress and links to each immediate subtask. The list starts collapsed and stays expanded while task data refreshes.
- Subtask status symbols are informational; the card's Complete action still applies to its main task.
- Relationship reads are shared across cards in each pane, refreshed on TaskNotes changes, and never polled by the timer tick.
- Unsupported or unavailable relationship reads are omitted. If completion statuses cannot be read, the list shows a total count without claiming how many are complete.

## Verification

The feature passed the production build, lint, 690 automated tests, and 13 vault-switch tests. Desktop checks used TaskNotes 4.18.2 in the isolated development vault: parent navigation, collapsed/expanded states, live completion-count changes, preserved expansion, and no horizontal overflow at card widths of 448 and 280 pixels. Screenshots were inspected from the running plugin.

Physical mobile behavior and installation of this published beta through BRAT have not been verified. This beta does not close outstanding acceptance items from earlier GSD phases.

## Install

In BRAT, add `judealnas/obsidian-tasknotes-task-ctrl` and select `0.5.0-beta.1`. BRAT's Latest tracking can also select this prerelease. GitHub's Latest stable release remains separate.

Minimum Obsidian version: 1.12.2. Relationship rows require the corresponding TaskNotes public relationship API methods; they were verified with TaskNotes 4.18.2. Regular timer compatibility is unchanged.
